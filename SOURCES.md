# Sources and attribution

## Dataset and base paper

Helber, P., Bischke, B., Dengel, A., & Borth, D. (2019). “EuroSAT: A Novel Dataset and Deep Learning Benchmark for Land Use and Land Cover Classification.” *IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing*, 12(7), 2217–2226. https://doi.org/10.1109/JSTARS.2019.2918242. Preprint: https://arxiv.org/abs/1709.00029.

EuroSAT RGB dataset, Zenodo record 7711810, https://doi.org/10.5281/zenodo.7711810. The dataset authors identify the dataset as MIT-licensed in their [official repository](https://github.com/phelber/EuroSAT#license). Follow the applicable Copernicus Sentinel Data Terms when reusing Sentinel-derived imagery.

## Implementation reference

The public project [leosky01/eurosat-land-use-classification](https://github.com/leosky01/eurosat-land-use-classification) was inspected as a workflow reference for fixed splits, comparative metrics, and interpretability. This project does not copy its source code, model weights, figures, results, or split manifest. All implementation and measurements here are generated for this project.
